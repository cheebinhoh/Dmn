Detailed Description

Compact generic finite-state-machine helper.

Each state is a functor callable with the Dmn_State instance; the machine stores these functors and uses m_next to select which to run next.

Usage example:

Dmn_State s("example");
s.setStateFnc(step1, 1);
s.setStateFnc(step2, 2);
while (s.runNext()) // drive the machine
;
