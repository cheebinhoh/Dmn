Detailed Description

Lightweight DMesg handler wrapper used by the DLock prototype.

publishSnapshot() only validates the supplied snapshot; it does not write to DMesg. postToOwnContext() schedules work in the inherited handler context, but the local acquire implementation does not use that path.
