Detailed Description

An owned D-Bus value with its wire type preserved.

Container factories require their element/key/value signatures explicitly, which preserves the type of empty arrays and dictionaries. Container access is const-only; copying a value is safe and shares immutable container storage.

This is the data model at the generic D-Bus client boundary: client methods accept and return these values, and the private client codec translates them to and from libdbus messages. Higher-level clients such as Dmn_BluezClient interpret the typed values as service-specific properties and events. This class is transport-independent; it does not connect to a bus, encode messages, or assign BlueZ meaning to a value.
