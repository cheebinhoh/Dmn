Detailed Description

Reusable BlueZ device setup and ANCS monitor orchestration.

Copyright © 2026 Chee Bin HOH. All rights reserved.

Overview

This facade owns the BlueZ inventory client, BlueZ GATT backend, and ANCS session client. It moves device selection, optional discovery, pairing, connection, service readiness, and ANCS startup out of terminal frontends. Applications receive owned ANCS events through the configured callback and can present them in a terminal, GTK interface, or another frontend.

The synchronous start operation performs bounded BlueZ and GATT calls. GUI applications must invoke it away from their UI thread and marshal event callbacks onto their UI context. Setup progress is reported synchronously on the thread calling start. Calls must not race object destruction; stop serializes with startup and does not cancel an in-progress setup. The facade does not disconnect or unpair the selected device during stop.
