Detailed Description

Reusable selected-device setup and ANCS event client.

Startup resolves an exact device name or Bluetooth address in the current BlueZ inventory, discovers it on one selected powered adapter when absent, pairs it when needed, connects it when needed, and starts the ANCS session. Device names are matched exactly with ASCII case-insensitivity. Startup addresses are matched case-insensitively. Startup progress can be observed using the configuration callback. The callback is installed before startup and receives serialized ANCS events according to Dmn_AncsClient's callback contract.

Select, connect, and start monitoring one exact device.

This operation is synchronous and bounded by config. If the target is already connected, BlueZ is also asked to connect remaining auto-connectable profiles before ANCS startup. Pairing and link state are retained after the monitor stops. stop() serializes with this operation and does not cancel an in-progress setup.
