Detailed Description

Move-only RAII token that owns one signal subscription.

Destroying or explicitly cancelling the token removes its match and suppresses future callback admission. A default-constructed token is empty. Cancellation is idempotent and does not wait for a callback already running on the client's callback worker to finish. The token may outlive its client; cancellation then has no effect because shutdown has already removed the subscription.
