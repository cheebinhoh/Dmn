Detailed Description

Access one selected device's remote GATT tree through BlueZ.

This optional Linux backend uses the generic Dmn_DbusClient and BlueZ's system-D-Bus GATT API. It neither connects nor pairs devices implicitly. Callers must explicitly connect using Dmn_BluezClient, wait for service resolution, and then inspect or operate on the current GATT tree.

Service and characteristic identifiers are current BlueZ object paths carried as opaque strings. They must be discarded after disconnect, service change, or BlueZ owner loss. Callback delivery is serialized by the D-Bus client's callback worker.
