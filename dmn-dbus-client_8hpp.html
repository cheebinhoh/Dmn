◆ Dmn_DbusBusKind

enum class dmn::Dmn_DbusBusKind
strong

Selects the D-Bus bus to which this client connects.

Session and System select the standard buses by kind. Address selects the exact caller-supplied address of a D-Bus bus daemon; that address can refer to either standard bus or to a separately started private bus instance. Every option creates a dedicated client connection. "Private connection" means a connection owned by this client, not a separate bus daemon. Direct peer-to-peer connections to a service process are not supported.

Enumerator
Session 

Open a dedicated client connection to the current user's session bus.

This uses the shared session bus; it does not start a separate bus.

System 

Open a dedicated client connection to the machine's system bus.

This uses the shared system bus; it does not start a separate bus.

Address 

Connect to the bus daemon at the exact caller-supplied address.

Use this for an explicitly addressed system/session bus or a separately started private bus instance. The address must identify a bus daemon, not a service process accepting a direct peer-to-peer connection. No session/system fallback is attempted.
