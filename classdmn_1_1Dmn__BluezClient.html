Detailed Description

Manage BlueZ inventory, explicit device actions, and one scan session.

Production instances connect only to the system bus. Event callbacks are serialized on a client-owned worker, outside the libdbus dispatch thread. Callbacks must not throw or destroy this client.

Ask BlueZ to connect any remaining auto-connectable profiles.

Unlike connectDevice(), this always calls Device1.Connect, even when Connected is already true. BlueZ may use this to connect a remaining profile or the disconnected bearer on a dual-mode device. It does not select a specific bearer or guarantee that GATT services will resolve. BlueZ's AlreadyConnected and InProgress responses, and its Failed / "Operation already in progress" response, are treated as an already-issued request; callers must separately verify the state they need.

Request connection to one explicitly selected known device.

The selector may be a case-insensitive device address or an exact current device object path. When multiple adapters contain the address, provide their address or object path in adapterSelector. This operation does not invoke Device1.Pair or install a pairing agent; BlueZ may still initiate its normal system pairing/authorization flow when the device requires it. An already-connected device is an idempotent success with no D-Bus call.

Explicitly pair one selected device using BlueZ's default agent.

This operation calls Device1.Pair unless the current inventory already reports the device paired. Dmn does not register a pairing agent, request trust, or start discovery; BlueZ's configured default agent handles any required user interaction. Pairing may connect the device and resolve its services as part of BlueZ's documented operation.

Parameters
deviceSelectorBluetooth address or current object path in inventory.
adapterSelectorOptional adapter address or current object path.
timeoutFinite method timeout; zero selects the configured default.
Returns
Success or the typed local/remote BlueZ error. A missing default agent or user cancellation is returned as a remote error.
