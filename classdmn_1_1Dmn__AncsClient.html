Detailed Description

Reusable, backend-neutral ANCS session over one borrowed GATT client.

The client never pairs or connects the selected device. Its caller must arrange link setup first. GATT callbacks are copied to ANCS-owned queues; application events are serialized on an ANCS worker and never delivered on the backend's callback thread. Control Point writes use a separate worker so a slow acknowledged write cannot block notification intake.

Resolve ANCS on a ready GATT link and subscribe to its sources.

This bounded synchronous operation waits for service resolution, locates the three required ANCS characteristics, subscribes to Data Source first, then Notification Source, and returns only after both subscriptions are ready. It does not pair or connect the device.
