Detailed Description

Finite resource bounds applied to one generic D-Bus client.

Configuration values must be positive and within the libdbus/platform limits checked during client construction. Calls beyond the effective in-flight cap are rejected. Signal deliveries beyond either callback-queue cap are dropped and counted in Dmn_DbusClientStatus.

Additional cap on in-flight calls and active subscriptions.

There is no separate local command FIFO in this implementation. The in-flight call cap is the smaller of this value and max_in_flight_calls.
