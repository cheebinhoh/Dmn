Detailed Description

template<class DMesgBase = Dmn_DMesg>
class dmn::Dmn_DLock< DMesgBase >

Local-only DLock prototype constrained to a Dmn_DMesg base.

This class currently serializes acquisitions only within its own in-memory table. It does not publish snapshots, synchronize handlers, enforce leases, or implement the publisher-serialized distributed-lock design. The template constraint prevents instantiation with Dmn_DMesgNet; it does not make this prototype suitable for distributed use.
