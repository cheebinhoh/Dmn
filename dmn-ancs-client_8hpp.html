Detailed Description

Public ANCS values and backend-neutral protocol parsing primitives.

Copyright © 2026 Chee Bin HOH. All rights reserved.

Overview

This header defines the owned value/error vocabulary used by the ANCS client and the bounded protocol parsers shared by that client. It depends only on the backend-neutral GATT contract and standard C++ types; no BlueZ, D-Bus, iOS SDK, or user-interface type crosses this boundary.

The notification-source parser decodes one complete eight-byte ANCS event. The data-source reassembler accepts arbitrary byte fragments for one serialized Get Notification Attributes response. It reports completion only after every requested attribute tuple has been fully received and validated.

Design constraints

  • Notification UIDs and parser instances are scoped to one live ANCS session; neither is a durable notification identity.
  • Data Source responses have no independent request identifier. The caller therefore serializes requests and creates one reassembler per active UID.
  • Every parser input and accumulated response has a finite byte bound. Invalid framing is a typed error rather than an unchecked read or success-shaped partial result.
