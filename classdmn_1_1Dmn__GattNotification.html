Detailed Description

Move-constructible owner for one enabled characteristic notification.

Call stop() to observe a StopNotify failure. Destruction also attempts cleanup, but cannot report a remote cleanup error. The token retains the backend resources needed to stop the notification even if its client wrapper is destroyed first. Move assignment is disabled because it cannot report a failed cleanup of the currently owned notification.
