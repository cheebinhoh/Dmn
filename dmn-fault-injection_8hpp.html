Detailed Description

Fault injection helpers for Dmn.

Copyright © 2026 Chee Bin HOH. All rights reserved.

This header provides a thin wrapper around libfiu failure points.

Fault points do not initialize libfiu themselves. The process entry point must initialize libfiu before enabling points; fiu-run does this for tests.
